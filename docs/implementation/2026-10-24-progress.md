## Execution rulings

- Work in the supplied checkout on a feature branch, with separate file ownership for concurrent tasks. The user requested immediate implementation within 30 minutes; a second checkout would complicate review and dependency sharing. Risk: changes share one working tree, mitigated by explicit file ownership and final integrated checks.
- Keep the independently versioned rule agent in `agent/` for one reviewable delivery. It can later move into its planned separate repository. Risk: repository extraction and external release automation remain follow-up work.
- Keep demonstration script rules in `examples/script-rules/` rather than modifying the separate `rules` submodule. The examples are synthetic and do not satisfy the public rule publication corpus gate. Risk: users must explicitly load these demonstration rules until reviewed public rules exist.
- Preserve binary freeze version 3; emit script freeze version 4 and support reading both. Risk: older capa rejects new script freezes, which is intentional rather than silently losing statement evidence.
- Production publishing remains disabled until deterministic checks, reviewed sample rights, compatibility pins, and human review are satisfied. A dry-run package is the deliverable for unreviewed proposals.

## Final implementation inventory

- Native Go helper: pinned grammars for all three languages, source map, schema validation, command/version CLI, conservative calls/variables/literals/structures, alias handling and uncertainty diagnostics. Built Linux amd64 helper locally.
- capa integration: script feature classes, sibling statement scope, rule indexing/subscopes, statement-local matching and function/file aggregation, CLI/automatic format selection, bounded helper transport and accurate helper provenance.
- Persistence and rendering: script freeze v4, retained binary v3 compatibility, JSON/protobuf script metadata/features/layout, correct dependent rule evidence even for statements with coincident offsets.
- Official tooling: branch-aware script format lint, statement scope support, formatted demonstration rules with synthetic hashed examples. Official thorough linter passes against bundled synthetic samples.
- Agent module: Go ADK/Gemini adapter (live calls explicit), evidence and sample intake, offline proposal replay, strict citations, SQLite claims/audit, fixed-command validation, exact positive/negative sample results, safe rule destinations and private local packages. Public publication remains disabled.
- Agent auxiliary components: recorded GitHub issue/RSS/Atom/JSON intake, approved documentation retrieval, bounded repair library. Network polling/scheduling, integrating documentation into model citations, repair CLI wiring, and automatic pipeline resumption remain unfinished.
- Build/CI: `scripts/build-script-tools.sh` builds both modules; added CI definitions for native Linux/Windows/macOS builds, Python 3.10/3.13 integration, and Go race/vet checks. Remote CI has not run in this local session.
